About Project

AI-Based Face Detection and Head Count System
Introduction

A web application that detects human faces from a live webcam or uploaded images, draws bounding boxes and counts the heads in view. It converts an OpenCV desktop script into a full web system.

Objectives
  • Detect and count visible faces in real time
  • Support webcam and image input
  • Store detection history in a database
  • Present results in a clear dashboard
Technologies

HTML5, CSS3, JavaScript, Bootstrap 5 - Python, Flask REST API - OpenCV, NumPy - SQLite

AI model

YuNet (cv2.FaceDetectorYN) lightweight face detector in ONNX format, file face_detection_yunet_2026may.onnx. It counts detectable faces; fully hidden or severely blurred faces cannot be detected.

Features
  • Live detection via browser getUserMedia()
  • Image upload with annotated result
  • History with view and delete
  • Statistics dashboard
